Méthode de vérification

Ce qui a été exécuté
  • Chaque TD a été rejoué du début à la fin avec Terraform 1.17 (providers local 2.9.1, random 3.9.1, docker 4.2.0), puis détruit. Les extraits « observé » sont de vraies sorties, parfois abrégées avec ….
  • Le TD 8 a réellement lancé nginx : réponse HTTP 200 sur le port 8000, remplacement du conteneur vers 8080, puis destruction sans conteneur restant.
  • Les noms aléatoires (suitable-tiger…), identifiants et empreintes seront différents chez toi.
Quand la doc et la réalité divergent

La page de documentation des outputs laisse entendre qu'un output sensible s'affiche <sensitive> avec terraform output NOM. En 1.17 j'ai observé que terraform output (seul) masque la valeur, mais que terraform output NOM, -raw et -json l'affichent en clair. Le site indique ce qui a été observé.

Limites

  • Ce parcours enseigne les fondations. Il ne couvre pas en détail un cloud particulier (AWS, Azure, GCP), HCP Terraform, ni les Stacks.
  • Les versions évoluent : vérifie toujours la documentation correspondant à ta version (terraform version).
  • Projet de formation personnel, non affilié à HashiCorp.
